測試建議

1. 先確認你已在 Google Cloud 啟用 Cloud Speech-to-Text API 並把它加進金鑰的 API 限制，否則會出現 403。
2. 先在 Safari 測一次；再加入主畫面、從圖示打開（APP 環境）測一次——後者最關鍵。
3. 把「辨識結果」和「錯誤/診斷」拍給我或告訴我。
常見錯誤：403=API 沒啟用/金鑰沒加這個 API、PERMISSION_DENIED=同上、麥克風不給=權限被拒。
